# 🛒 X-store

Tienda online moderna y escalable.

## ✨ Features
- 🛍️ Catálogo de productos
- 🔍 Búsqueda y filtros
- 🛒 Carrito de compras
- 💳 Checkout con pagos
- 👤 Autenticación de usuarios
- 📦 Panel de administración

## 🚀 Instalación
```bash
git clone https://github.com/tu-usuario/X-store.git
cd X-store
npm install
cp .env.example .env
npm run dev
